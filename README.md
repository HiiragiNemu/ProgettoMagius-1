## 本轮变化

- 1.1.2 配合 delta 31 支持正常输入中文玩家名（1～8 个 Unicode 字符），保存后在设置、本人资料及后续加载中保持一致。未改名时才显示“小丘比”；玩家 ID、邀请码、他人资料及角色名称不变。名字保存在本机，卸载或清除应用数据会移除。
- 十三份固定 CN BASE 默认优先使用迁移后的 EdgeOne／ESA，失败回退个人线路。两者不参与 APK、Scenario、完整 JS、delta 或版本元数据分发。

- 1.1.1 的 APK 更新只使用个人 Cloudflare 与本公开 GitHub；在同一发布者、同一维护线内比较版本。
  游戏 API 与 APK 更新来源分开管理，其他维护线的 2.0 不作为本线客户端更新候选。
  旧缓存、退役分支链接及备用更新入口也遵守这一边界。
- 保留 1.1.0 的下载页调整：慢速下载不再反复询问“继续／重下”，资源行紧凑显示版本与实际来源，横幅和按钮对齐。
  历史安装没有来源记录时不补猜；新下载成功后保存真实线路。
- 手动重下 Scenario 或完整 JS 后，继续从网络重下并校验应用最新累计 delta；单独重下 delta 有对应进度。
  保留版本、文件身份、串行安装与防回退校验，安装链成功后才记录版本。
- delta 28 修复侧栏文字颜色及国服“必要的CC／持有CC”用语，但用户复验发现魔力解放与属性强化页仍会空白。
  delta 29 已直接补齐两页真实模板的六项标签；浏览器切页回归通过，设备视觉效果仍由维护者验收。
  角色名称与版本标签按全表核对：有国服记录时采用国服，缺失记录时采用中文 Wiki；不机械追加 `ver.`。
- 支持与贡献公告采用维护者定稿、个人 GitHub 入口，并接入外部链接处理；保留原译者署名及统计规则。

1.1.2 的签名、对应源码、公开包完整下载和 delta 31 累计内容已核验。
本轮按维护者要求由维护者自行实机验收，代理没有安装或进入设备；新版本的实机验收状态仍为 `PENDING_MAINTAINER`。
历史版本的用户验收不改写为 1.1.2 的实机验收。

## 分发与维护

个人客户端和资源维护仓现已私有，本玩家分发仓保持公开。
私有化后已实际通过维护端鉴权和私有源到本公开仓的同步；玩家无需访问维护仓或提供令牌。
独立 Cloudflare 更新入口仅依赖公开输出。迁移后的 EdgeOne／ESA 仅用于 CN BASE 专用白名单，不恢复旧域名或组织 APK 更新通道。
TLS 证书、包身份和内容校验保持开启，不通过放宽校验处理连接错误。

先上传对应源码、包和清单，再提升客户端版本门槛；同版本不同内容与版本回退拒绝发布。
只同步核定的玩家附件，不公开私人资料、凭据或维护审计全集。
没有内容变化的附件不重打、不重传，也不为了刷新日期改变原有文件身份。
APK 与资源分开发布，构建成功不自动触发发布；实机验收和维护者明确选择的自行验收发布模式分别记账。
