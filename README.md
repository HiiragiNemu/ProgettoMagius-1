历史维护草稿不作为玩家下载入口。

## 分发与维护

本仓是面向玩家的独立公开输出，不要求玩家访问维护源仓或提供访问令牌。
当前分发为公开 GitHub 与独立 Cloudflare 线路；已退役的旧 CDN 不自动补回。
下载保留 TLS 证书、文件身份和内容校验，不通过放宽校验处理连接错误。

发布时先放置包和清单，再提升配套版本门槛；同版本不同内容、版本回退及不一致的镜像应被拒绝。
仅同步核定的公开附件，不发布私人资料、凭据或维护审计全集。
无内容变化的附件不重打、不重传，也不为了刷新日期改变既有文件身份。
客户端 APK 与资源分开发布；构建成功不自动代表最终 APK 已获实测批准。

源仓将来私有化时，维护端跨仓同步使用 Actions 凭据，玩家仍从本公开入口下载。
切换仓库可见性后的凭据、同步联动及匿名下载需单独复验；当前没有把这项未来切换视为已完成。
源码镜像同步成功也不替代公开资源附件校验。

字体及原始署名、许可沿用客户端交付；资源同步核验不替代客户端字体的实际画面验收。
